# Tienda Checador Legal MX

Página de venta del software Checador Legal MX con carrito de compras, checkout funcional y pedidos guardados en Supabase.

## Stack

- React + Tailwind CSS
- Supabase (base de datos de pedidos)
- Netlify (hosting)
- Mercado Pago (pagos, pendiente de activación)

## Desarrollo

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Deploy

Conectado a Netlify con auto-deploy desde `main`.
